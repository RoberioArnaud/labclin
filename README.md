# LabClin

Landing page institucional da **LabClin — Laboratório e Clínica Integrada**, desenvolvida sob demanda para uma clínica real. O projeto apresenta serviços, unidades de atendimento e canais de agendamento da instituição.

🔗 [Acessar site publicado](https://lynxs.site)

## Sobre o projeto

O site foi pensado com foco em dispositivos móveis e em uma experiência simples: informar os serviços disponíveis e direcionar o visitante rapidamente para o atendimento pelo WhatsApp.

## Funcionalidades

- Apresentação institucional e história da LabClin;
- Serviços de consultas médicas, exames laboratoriais, DNA e sexagem, biópsias e citológico;
- Informações das unidades de Cacimba de Dentro, Araruna e do ponto de coleta no Distrito de Logradouro;
- Horários de atendimento;
- Botões de contato e atalho flutuante para WhatsApp;
- Layout responsivo para celular e desktop.

## Tecnologias

- React 19
- TypeScript
- Vite
- TanStack Router
- Tailwind CSS
- Lucide React
- Bun (gerenciador de pacotes e execução local)
